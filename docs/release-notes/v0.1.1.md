# MDB Test Bench v0.1.1

## English

This is the first distributed MDB Test Bench release. It includes:

- MDB Cashless encoder/decoder and significant Level 1 support;
- partial, explicitly documented Level 2 and Level 3 structures;
- deterministic Simulator and asynchronous test scenarios;
- Wafer Discovery with exact raw TX/RX chunks, timing, markers and conservative analysis;
- privacy-safe `.mdbcap.json` export/import and offline reanalysis;
- fixed Windows capture spool finalization and file-sharing lifecycle;
- `en-US` and `pt-BR` interface and user documentation;
- self-contained Windows x64, macOS ARM64/x64 and Linux x64 downloads.

Structured control of Wafer MDB-RS232 `2022061K5` is not yet enabled. The Wafer protocol is pending physical capture validation. Simulator/CI success does not establish electrical or physical compatibility.

macOS bundles are unsigned/not notarized and can trigger Gatekeeper. Linux still requires native desktop libraries. Verify downloads using `SHA256SUMS.txt`.

## Português (Brasil)

Esta é a primeira release distribuída do MDB Test Bench. Ela inclui:

- encoder/decoder MDB Cashless e suporte significativo ao Level 1;
- estruturas parciais e explicitamente documentadas de Level 2 e Level 3;
- Simulador determinístico e cenários de teste assíncronos;
- Descoberta Wafer com chunks raw TX/RX exatos, timing, marcadores e análise conservadora;
- exportação/importação privacy-safe `.mdbcap.json` e reanálise offline;
- finalização do spool e ciclo de compartilhamento de arquivo corrigidos no Windows;
- interface e documentação de usuário em `en-US` e `pt-BR`;
- downloads self-contained para Windows x64, macOS ARM64/x64 e Linux x64.

O controle estruturado do Wafer MDB-RS232 `2022061K5` ainda não está habilitado. O protocolo do adaptador depende da validação por captura física. O sucesso no Simulador/CI não comprova compatibilidade elétrica ou física.

Os bundles macOS são unsigned/not notarized e podem gerar alertas do Gatekeeper. O Linux ainda requer bibliotecas nativas do desktop. Valide os downloads com `SHA256SUMS.txt`.
