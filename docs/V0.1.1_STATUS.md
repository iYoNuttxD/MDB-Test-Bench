# MDB Test Bench v0.1.1 status

This status separates implemented software behavior from simulator evidence and physical validation. Passing automated tests does not establish MDB electrical conformance or compatibility with Wafer revision `2022061K5`.

| Area | Implemented | Automated validation | Simulator validation | Requires hardware validation | Known limitation |
|---|---|---|---|---|---|
| Architecture | Core, Transport, TestEngine and Avalonia App boundaries | Project-reference and dependency audit; Release build | N/A | No | App composes dependencies manually rather than using a DI container |
| MDB Level 1 | Significant command/response subset, checksum, values, devices #1/#2 | Normative encoder/decoder/round-trip vectors | Initialization and vend flows | Electrical timing, mode bit and adapter mapping | Not a full conformance implementation |
| MDB Level 2 | Revalue and shared L1/L2 shapes | Codec and feature-level tests | Partial flows | All physical behavior | Time/date and obsolete file operations absent |
| MDB Level 3 | Expanded values/options infrastructure, independent capabilities | Codec/value/capability tests | Partial | Negotiation and all physical behavior | Most optional transactions remain unimplemented |
| Simulator | Normal, approve, deny, timeout, malformed and unexpected modes | End-to-end state/log/scenario tests | Yes | No | It is deterministic development behavior, not a device certification model |
| Structured hardware | Semantic command and MDB-byte preview | Guard regression test | Simulator sending works | Wafer codec | Physical send is deliberately disabled |
| Raw hardware debug | Discovery-only, confirmation, wire settings, exact TX capture | Wire-format and controller tests | Discovery simulator | Real serial/adapter behavior | No automatic probe or framing inference |
| Discovery capture | Raw chunks, TX, markers, lifecycle/errors, monotonic timing, streaming spool | Concurrency, size, preservation and validation tests | Start/marker/TX/RX/stop/export/open | Timestamp behavior under real drivers | No per-byte timing from `System.IO.Ports` |
| Offline analysis | Import, filter, MDB overlay, statistics and summary/reexport | Golden capture and restart round trip | Yes | No | Interpretation remains conservative and may be Unknown |
| Distribution | Self-contained Windows x64, macOS ARM64/x64 and Linux x64 workflows | Local build/tests and CI definition | Native smoke option | Native release QA on each OS | macOS output is unsigned/not notarized |

## Integrated primary path

```text
Scenario / Manual semantic command
  -> IMdbCashlessEncoder
  -> standard MDB byte block
  -> SimulatedCashlessTransport
  -> IMdbCashlessDecoder
  -> VmcStateMachine
  -> structured MDB traffic log
```

The physical path stops at `IWaferProtocolCodec`: there is no production implementation and no default registration. Discovery bypasses that missing semantic codec intentionally and records unmodified serial chunks.

## Release decision

v0.1.1 is suitable for simulator work, offline capture analysis, and controlled Discovery sessions. It is not yet suitable for structured control of the reported Wafer adapter. Promotion of hardware structured sending requires repeatable captures, reviewed framing/checksum/polling evidence, an implemented codec, regression vectors derived from that evidence, and a new release review.
